# Box Score development agenda

## First milestone

Build and test the complete site using a small, interconnected set of eight
published boxers:

Muhammad Ali, Joe Frazier, George Foreman, Larry Holmes, Marvin Hagler,
Sugar Ray Leonard, Thomas Hearns, and Roberto Durán.

Additional unpublished boxer documents will be needed for opponents who
appear in those eight fight histories. Once the complete workflow is tested,
we can expand to more boxers and bouts.

## Proposed documentation

- **[docs/schema.md](docs/schema.md)** — boxer and fight document design
  (**this file exists in the initial documentation draft**).
- `docs/deployment.md` — future production setup, configuration, and backup
  instructions.
- `docs/data-sources.md` — future research, source-quality, and data-import
  conventions.
